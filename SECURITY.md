# 🛡 Security Policy

## Supported Versions
We provide security updates for the latest stable version of TG2AI.

## Reporting a Vulnerability
If you discover a security vulnerability, please do NOT open a public issue. Instead, send an email to security@tg2ai.io (placeholder).

## Safety Mandates
- Never log Telegram Bot Tokens.
- Only scrape public channel data.
- Sanitize all inputs before parsing.
